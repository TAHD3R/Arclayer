# Use the Operations Workbench direction for Commerce

**Status:** accepted

The Commerce redesign will use the Operations Workbench direction: PageHeader-led pages, server-backed filterable DataTables, compact readable rows, and URL-restorable investigative Drawers. Plans and Configuration may use structured editing panels inside that same shell, but they will not introduce a competing card-heavy or evidence-only visual system.

**Consequences**

- Shared table, Drawer, toolbar, and PageHeader compositions should be designed once and reused across Commerce pages.
- Visual hierarchy comes from neutral surfaces, borders, spacing, and semantic status—not decorative metrics or large card mosaics.
- Narrow layouts collapse the Drawer into a Sheet while preserving list context and actions.
