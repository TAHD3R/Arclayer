# Adopt shadcn-admin as a reviewed source donor

The Platform Console adopts the MIT-licensed `satnaing/shadcn-admin` project as its reviewed source and composition donor because its Vite, TanStack Router/Query/Table, React Hook Form, Zod, Lucide, Tailwind, responsive Sidebar, command search, DataTable, and form patterns align closely with Arclayer's existing frontend stack. Arclayer does not fork it as a second application or add it as a runtime dependency: every adopted file records provenance and is adapted behind Arclayer's primitives, tokens, routing, data, authorization, i18n, accessibility, and testing contracts; Clerk, Recharts, duplicate primitives, foreign icon/form/theme/loading stacks, demo pages, KPI cards, and template product models are excluded, and the resulting Platform Console replaces the legacy shell through a visual hard cut without a compatibility facade.
