# Use federated domain search in the Command Center

The Platform Console Header Command Center combines authorized navigation, recent typed destinations, common workflow entry points, and federated server search from build-registered providers owned by enabled Platform Domains. Each provider independently enforces Platform API permissions, field redaction, ranking, pagination, result identity, and typed navigation; the frontend neither downloads domain datasets nor builds a copied universal index, and provider failures remain explicit without blanking successful groups. Results reveal only the minimum recognizable context, search text is not persisted, and workflow entries never commit mutations inside the palette or bypass canonical preview, confirmation, permission, idempotency, durable-result, and Audit contracts.
