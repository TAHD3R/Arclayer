# Layer list, Drawer, and full-page detail

Platform Console operational work begins in a Queue or DataTable, uses a URL-restorable right-side Drawer for quick investigation without losing list context, and escalates only complex or durable workflows to a dedicated typed route. A Drawer must add cause, impact, affected scope, chronology, related evidence, and an authorization-aware next action rather than repeating row fields, generic values, raw JSON, or decorative charts; objects with multiple peer views, long history, resumable steps, independently linkable evidence, or complex configuration receive a full page, while rows with no additional decision value receive no detail affordance. Low-risk changes may remain inline, bounded forms use Dialogs, and high-risk or evidence-heavy mutations belong on the dedicated page instead of turning the investigative Drawer into a generic form container.
