# Make bulk actions explicit domain capabilities

Platform Console DataTables gain no automatic bulk CRUD: an owning Platform Domain may expose a bulk action only after defining its exact action code, eligible states, action-scoped permission, input, idempotency, preview and commit semantics, per-item results, retry, Audit evidence, and recovery path. The UI distinguishes explicitly selected ids from all records matching a server filter, and all-matching, high-risk, cross-Workspace, long-running, or partially successful work uses a revision-bound preview and durable operation whose pending and per-item outcomes remain explicit; retries target only eligible failed items. Instance Owner transfer, commercial correction, credential replacement, permission elevation, and other individually evidenced actions remain single-record workflows unless a later domain contract proves safe bulk semantics.
