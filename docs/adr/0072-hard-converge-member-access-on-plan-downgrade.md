# Hard-converge member access on Plan downgrade

An access-reducing Plan change requires a revision-bound Plan Access Convergence preview before scheduling, and a target Free Plan also requires the current Owner's Free Workspace allowance at preview and effectiveness. At the effective boundary Arclayer end-dates unsupported custom roles, member role assignments, invitation role bindings, and Feature Seat Assignments, applies Fixed Member access when role management is unavailable, and retains only explicitly selected assignments within a lower seat limit. Ended configuration remains historical Audit evidence and never returns automatically after a later upgrade; unsafe Provider Portal downgrades are unavailable, and an uncorrelated Provider event becomes an explicit fail-closed reconciliation problem rather than silent cleanup or continued paid authority.
