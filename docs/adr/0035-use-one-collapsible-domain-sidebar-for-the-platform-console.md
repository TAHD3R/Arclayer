# Use one collapsible domain Sidebar for the Platform Console

The Platform Console uses one responsive Shell whose single collapsible left Sidebar is the primary navigation authority: Operations Inbox is pinned first, enabled and authorized Platform Domains follow as localized product groups, and only the active domain expands its peer pages by default. The Header is limited to breadcrumbs, permission-filtered command search, return-to-product, locale, theme, and account utilities; narrow layouts present the same hierarchy in a Sheet, while collapsed desktop navigation preserves localized tooltips and accessible names. Sidebar, command search, breadcrumbs, and mobile navigation share the Platform Capability and Platform Permission projection, and the existing path-selected settings, tenant-directory, observability, or other nested navigation shells are removed in the hard cut rather than retained as a second hierarchy.
