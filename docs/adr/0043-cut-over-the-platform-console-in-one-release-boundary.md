# Cut over the Platform Console in one release boundary

Arclayer develops and verifies `apps/platform` through incremental backend, migration, and domain waves but does not expose it as the official production entry until every retained Platform Capability, Session and permission boundary, bilingual surface, migration item, and browser acceptance case passes one frontend cutover gate. The cutover release enables the Platform Host and removes every Platform route, navigation entry, page, client, store, translation, skeleton, and build reference from `apps/admin` at the same boundary, so operators never traverse two Shells or an embedded legacy page. Preparatory database and Platform API changes may be explicitly forward-compatible for a rehearsed rollback of the previous complete release, followed by a declared retirement migration; rollback never uses per-domain flags, aliases, or a compatibility facade inside the new application.
