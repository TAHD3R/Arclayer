# Support server-persisted personal table views

Every Platform Console operational DataTable has one versioned domain-defined default view and allows a Platform Operator to save personal views containing backend filter codes and values, ordering, visible columns, column order, and density without storing result data, aggregates, pagination, selection, Drawer state, scroll, or free-text search history. Selecting a view expands its current effective state into a typed shareable URL, and the server revalidates it against capability, permission, filter-schema, and column revisions before querying; invalid or newly unauthorized conditions are omitted with explicit localized feedback rather than sent or hidden behind an empty result, while the stored view changes only through an explicit owner update. Team-shared, locked, published, formula, arbitrary-query, and snapshot views remain outside the contract.
