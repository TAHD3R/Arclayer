# Recover Operator MFA with one-time codes or an authorized reset

Each non-owner Platform Operator receives single-use recovery codes at MFA enrollment and may use one, after authenticating through the configured identity authority, only to enter bounded MFA re-enrollment; when no code remains, the Instance Owner or an Operator with exact reset permission may start the same recovery state for another Operator through action-bound Step-up Platform Verification. Either path revokes all target Platform Sessions, Step-up proofs, factors, and recovery codes while retaining but blocking current roles until the same identity completes new MFA enrollment; it never grants temporary authority, exposes factors, reactivates a deactivated Operator, or replaces the separate Instance Ownership Recovery boundary.
