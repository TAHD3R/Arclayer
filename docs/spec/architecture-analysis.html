数据库与基础设施

PostgreSQL + pgvector

主数据库。使用 Tortoise ORM 进行异步操作。pgvector 扩展支持向量嵌入，用于 AI 内容功能。迁移文件在 apps/api/src/migrations/。

Valkey 8.0

Redis 兼容的缓存和消息队列。用途：HTTP 缓存、TaskIQ 任务队列 Broker、会话存储。

Meilisearch v1.12

全文搜索引擎。用于内容搜索、站点搜索。Rust 编写，高性能。

RustFS

S3 兼容的对象存储（Rust 实现）。通过 boto3 访问。存储图片、视频、PDF 等媒体资产。

Traefik v3

反向代理和负载均衡。统一入口，路由到各个服务。

Mailpit + Dozzle

开发辅助：Mailpit 捕获 SMTP 邮件供调试，Dozzle 提供 Docker 日志 Web UI。

插件系统

架构

基于 pluggy 的钩子系统。插件可以是本地目录（plugins/）或安装的 Python 包。 每个插件通过 create_plugin() 工厂函数暴露，使用 @arclayer_hookimpl 装饰器实现钩子。

核心插件模块在 src/core/plugin/：loader（加载）、manager（管理）、runtime（运行时）、 lifecycle（生命周期）、extensions（扩展点）、config（配置）、specs（规范）。

Lifecycle应用启动/关闭、请求开始/结束
Service注册自定义服务到依赖注入
Route注册额外的 API 路由
Model扩展数据模型
Middleware注入自定义中间件
Event订阅业务事件

Turborepo 任务管线

定义在 turbo.json。支持 dev、build、typecheck、lint、format、test 以及 API 专属的 db:migrate、db:upgrade、jobs:worker、jobs:scheduler。 环境变量通过 passthroughEnv 传递数据库、认证、Valkey 配置。

架构决策
决策选择理由
后端 ORM Tortoise ORM (异步) 与 FastAPI 的 async/await 模型天然匹配，Django 风格的 API 降低学习成本
API 风格 REST + GraphQL 双协议 REST 用于标准 CRUD，GraphQL 用于灵活的内容查询和站点交付
前端路由 TanStack Router（文件系统） 类型安全的路由参数和搜索参数，原生支持懒加载和预加载
前端状态 Zustand + React Query 分工 客户端状态 (Zustand) 与服务端缓存 (React Query) 职责清晰分离
API SDK OpenAPI 自动生成 消除前后端类型不一致，减少手写 API 客户端代码
插件系统 Pluggy (Python) pytest 同款插件框架，成熟稳定，支持钩子发现和生命周期管理
后台任务 TaskIQ + Valkey async 原生支持，与 FastAPI/Tortoise ORM 共享同一事件循环模型
搜索 Meilisearch 开箱即用的中文支持、容错搜索、高性能，无需额外分词配置
Lint/Format oxlint + oxfmt (TS) / Ruff (Py) 全部使用 Rust 编写的工具，速度快 10-100x，交互式开发体验极佳
富文本编辑 PlateJS (Slate 之上) 插件化架构，支持自定义节点类型（代码块、表格、公式等），可扩展性强
样式方案 Tailwind CSS 4 + 设计令牌 原子化 CSS 零运行时开销，设计令牌确保视觉一致性
向量数据库 pgvector (PostgreSQL 扩展) 无需额外部署向量数据库，利用现有 PostgreSQL 基础设施支持 AI 功能
国际化 react-i18next (前端) + 自定义运行时 (后端) 19 个命名空间、2 种语言，按模块拆分翻译文件
