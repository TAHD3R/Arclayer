# Audit Artifacts

This directory stores project-level audit outputs and governance documents.

## Purpose

- Keep a versioned history of architecture and quality audits
- Track capability gaps against the product direction (self-host first, SaaS-ready, AI-native)
- Provide decision-complete governance policies for implementation phases

## Document conventions

- One snapshot report per audit cycle (date-prefixed)
- Stable strategy documents that evolve with decisions
- Generated machine reports should use `latest-*` naming to support CI and local checks

## Current files

- `2026-02-08-project-audit-and-gap-matrix.md`: Initial issue register and capability gap matrix.
- `2026-02-08-project-governance-policy.md`: Implementation policy, roadmap, and acceptance gates.
- `2026-02-08-issue-register.csv`: Curated issue register for governance tracking.
- `latest-quality-report.md`: Generated by `scripts/quality/audit_repo.py`.
- `latest-quality-report.csv`: Machine-readable findings generated by `scripts/quality/audit_repo.py`.
