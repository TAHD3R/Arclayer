# Guides

This directory contains operator-facing and workflow-oriented documentation.

It is intentionally separate from `docs/guidelines/`:

- `docs/guidelines/`: long-lived engineering standards and conventions
- `docs/guides/`: runnable how-tos, deployment notes, and environment setup

Current guides:

- `selfhost-compose.md`: single-machine Docker Compose stack (pgvector, RustFS, Meilisearch, Traefik edge, devtools)
